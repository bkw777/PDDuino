PDDuino OpenLog build
====================
Target: original SparkFun OpenLog, ATmega328P at 16 MHz.

Use Arduino AVR Boards 1.8.6 and Bill Greiman's SdFat 1.1.4.
Keep SdFat's USE_LONG_FILE_NAMES enabled (the library default).
SdFat 2.x is not a drop-in replacement.

In Arduino IDE select Arduino Uno as the compile profile. This selects the
correct MCU and clock; verify the bootloader/programmer on your OpenLog before
uploading. OpenLog Artemis, Feather and Teensy are not supported by this fork.

CLI (tested with Arduino CLI 1.3.1):
  arduino-cli core update-index
  arduino-cli core install arduino:avr@1.8.6
  arduino-cli lib install 'SdFat@1.1.4'
  ./tools/build.sh

The DSR input defaults to Arduino digital pin 6, active LOW. It requires an
additional wire to a free GPIO on the OpenLog, NOT the header's DTR/reset pin.
Set DSR_PIN / DSR_ACTIVE_LEVEL in PDDuino/board_OpenLog.h to match the actual
wiring, or use a compiler override:
  ./tools/build.sh --build-property 'compiler.cpp.extra_flags=-DDSR_PIN=6 -DDSR_ACTIVE_LEVEL=LOW'

No LED, debug console, sleep, DTR output, or card-detect GPIO is used.
See README.md for bootstrap, card exchange and validation instructions.
